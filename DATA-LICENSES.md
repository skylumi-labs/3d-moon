# Data licences

The code in this repository is under the licence in `LICENSE`. **That licence does not cover the data.** The maps, terrain,
imagery, catalogues, photographs and the 3D model the viewer ships or streams keep their own terms, listed below. Third-party
*software* (three.js, Astronomy Engine, Draco, Sentry, posthog-js, Tabler Icons, the Bruneton parametrisation) is listed with its
licence text in [`public/THIRD-PARTY-NOTICES.txt`](public/THIRD-PARTY-NOTICES.txt).

The **Credit id** is the row of the viewer's Credits panel (`src/ui/credits.ts`), and **Credit line** is the exact text that row
shows. Keep that text when you reuse the data. "Public domain" for NASA material follows the NASA media usage guidelines: NASA does
not claim copyright, asks for credit, and its insignia and pictured people must not imply endorsement. Several sources also ask
to be cited; the citation is part of the credit line. The SHA-256 of every data file in this repository is in
[`DATA-SHA256SUMS.txt`](DATA-SHA256SUMS.txt).

"Mirror" names the prefix of the hosted data mirror (best effort, no SLA) that serves the tiers too large for git. Every row below
is public-cleared: the mirror serves only these sources, and forks may read it.

## Restricted sources are excluded

The project also works, internally, with lunar data whose terms do not allow public redistribution, or have not been read. That
data is **not** in this repository, **not** on the mirror and **not** in the sample set, and none of this file's rows describe it.
It lives in its own tile prefixes and layer ids, tagged `licence: 'internal-only'`; `src/coverage/coverage.ts` drops such rows in
every production build, `scripts/assert-dist-public.mjs` fails a build that carries their strings, and the sample-set builder
(`scripts/build-sample-set.mts`) refuses them. Adding any such source to a public surface needs fresh permission from its owner and
a row here first.

## Open provenance notes

These are stated, not guessed. The upstream hosts could not be reached from the session that wrote this file;
`scripts/data-upstream-hashes.sh` downloads each public original and prints its SHA-256 so a maintainer can close them.

- **SVS 4720 inputs.** The SHA-256 of the shipped outputs is recorded; the SHA-256 of the 2019 input TIFFs is not.
- **HYG release.** The JSON was converted from an intermediate `hyg_mag6.5.bin` whose HYG release was not written down.
  `scripts/hyg-match.mts <hygdata_vNN.csv>` compares the shipped file with a given HYG release.
- **Lunar Module model.** The shipped GLB's byte count equals the size the NASA page lists; byte identity with the download is not
  yet confirmed by hash. The file is a Blender glTF export with Draco compression and WebP textures.
- **Panoramas.** The shipped WebP tiles are this project's re-encoding; the SHA-256 of the original JPEGs is not yet recorded.
